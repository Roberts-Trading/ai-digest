### Anthropic — Claude Protein Design Deep Dive (Any Lab Can Run Full Stack), Claude Gmail/Drive Continued Coverage, Claude Watermark Workarounds Found Within 4 Hours, Claude Code Limits Extended
- **Summary**: (1) **Claude protein design deep dive** (The Decoder, India Today, AI Weekly) — Further detail on yesterday's protein binder experiment. What's new is the layer above existing tools (AlphaFold, RFdiffusion, BindCraft) — a general language model researched the biology of each target, chose the docking site, installed programs from public repos, combined them across 24 different workflows, and delivered a finished ranking without any human touching a single design decision. All models used are open-source, so such campaigns are within reach for any lab. Claude succeeded on 14 of 15 targets (16 targeted, 15 produced usable measurements). 1,320 designs tested, 354 bound (26.8% overall hit rate). Looking only at designs Claude ranked first on its own list, 49% bound. Mythos Preview 35.1% per-target hit rate vs 10-15% industry. Opus 5 processed raw NMR (23 min) and LC-MS (19 min) data, purity 96.4% vs 96.33% lab. Claude corrected its own mistake (first found 2 of 4 missing signals, then found all 4). Anthropic published prompts, design data, and measurement datasets on Hugging Face for reproduction. Dual-use biology capabilities remain restricted; trusted access program being prepared. Team/Enterprise admins decide whether members can skip approvals. Limitations: cannot read Gmail attachment contents (metadata only), cannot extract images from Drive files, may struggle with large mailboxes or complex Gmail filters. Claude authenticates through user's Google account, mirrors Workspace permissions, retrieves minimum data needed. Retrieved connector data stored encrypted on Anthropic's servers; not used to train models. Also: 50% increased weekly Claude Code limits extended through August 31 (previously through August 19). (3) **Claude watermark workarounds found** (WIRED) — Within four hours of Anthropic confirming Claude models would globally embed invisible watermarks, developer Guillaume Meyer had published his override. Coders say they've already found workarounds to the statistical pattern watermarking system. The rapid developer response highlights the tension between Anthropic's watermarking implementation and the developer community's ability to circumvent it. (4) **Claude outage pattern continued** — The 7-incidents-in-6-days outage pattern (Aug 12-18) reported yesterday continued to be a story, with questions about whether Anthropic's infrastructure can keep up with its $65B run rate growth.

### Letta/Memory — OpenViking (ByteDance, 29K Stars, Unified Context Layer), TrueFoundry TrueForge (Open-Source Claude Managed Agents Rival), AWS Bedrock AgentCore (Persistent EC2 Runtime), Agent Memory Shifts from Storage to Control, Graphwise GraphRAG
- **Summary**: (1) **OpenViking (ByteDance Volcengine)** (Top AI Product) — ByteDance's cloud arm Volcengine open-sourced OpenViking, a unified context layer for AI agents. 29K GitHub stars (213 in a single day). Merges agent memory, knowledge RAG, and skills into one self-evolving layer. Treats context as a virtual filesystem under `viking://` protocol — agents browse memory with ls, tree, find instead of querying a black-box vector store. Content compresses into 3 tiers (L0 abstract, L1 overview, L2 details) loaded on demand. Self-evolving: the more an agent uses it, the better organized its context gets. Apache-licensed Python library + hosted API on Volcengine. Community building OpenClaw plugins. "Not another memory hack, but the standard layer every agent writes to."
