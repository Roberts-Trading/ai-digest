## Letta & Agent Memory

### Letta Releases FrontierMemory 1.0 — and the Harness Beats the Model
- **Summary**: Letta published **FrontierMemory** (Oct 21), a benchmark that scores agent memory by whether it improves downstream task performance — not recall. Agents get 665 transcripts of earlier work (only 219 relevant), write their own memories, and a second agent uses them on 15 tasks. Results: **the same Claude Opus 5.5 scored 73.3% in Letta Dream but 33.3% in Claude Managed Agents** — the harness gap is wider than the model gap. Harness table: Letta Dream 73.3%, Prime Agent 60%, OpenAI Agents SDK 40%, Claude Managed Agents 33.3%, Hermes Agent 26.7%. Model table (memory quality): Opus 5.5 and GLM-5.3 tied at 73.3%, Kimi K3 66.7%, GPT-6.1 Sol and Gemini 4 Argon 60%, Muse Wonder 46.7%, Grok 4.7 33.3% — but GPT-6.1 Sol wrote memory at $0.77/task vs $2.80 for Opus. Practical findings: instructions with explicit triggers beat summaries; rules overfit to one past run fail to transfer; memory written by one model helps other models too (portability). Caveats: 15 tasks, one attempt each (±6.7pp), Letta's own benchmark with its harness on top.
- **Sources**: https://thenewstack.io/letta-frontiermemory-agent-harness-benchmark/; https://ailookout.news/blog/letta-frontiermemory-benchmark-scores-agent-memory-by-the-work-it-improves/
- **Significance**: This is the first benchmark that measures what we actually care about — whether memory makes future work better. The headline ("harness matters as much as the model") validates the entire memory-first architecture this agent runs on, and the "instructions with triggers beat summaries" finding is directly actionable for how we write memory blocks.
