### Letta/Memory — Agentic Context Management (ACM) Paper, Recuris Memory Framework, Prime Agent 95.5% ARC-AGI-3, Agentic Procedural Memory Analysis, Lody Open-Sourced, IBM Granite 4.2
- **Summary**: (1) **Agentic Context Management (ACM) paper** (LavX, DonWeb) — NEW. arXiv paper (July 23, 2026, Gaurav Dadhich). Proposes ACM as framework for controlling what AI agents remember, retrieve, and compress across conversations and organizational boundaries. Treats agent memory as lifecycle: selection, extraction, storage, retrieval, consolidation, forgetting, context compression. Argues traditional storage-and-retrieval view (RAG, LangChain, MemGPT, Letta) is insufficient — "manages context as a storage and retrieval problem: save, search, paste." ACM: context management is a lifecycle that starts before storing and ends after retrieval. Reference implementation: Maximem Synap, a multi-tenant service implementing five primitives. Reports 92% on LongMemEval and 93.2% on LoCoMo. Without memory management, token costs grow quadratically with conversation length; with validated compacting, costs become linear while preserving fidelity. Two extensions: decision-level context (reasoning inputs behind past choices) and organization-level context (policies, team knowledge, project state without over-aggregation). Long-term value depends on whether ideas hold under real workloads, permission boundaries, and months of accumulated context. (2) **Recuris: Recursive Experiential-Working Memory** (SingularityMoments, GenAI Agent News) — NEW. arXiv paper (Aug 26, 2026). Recuris is a recursive Experiential-Working Memory architecture for long-horizon agent harnesses. Splits memory into Working Memory (immediate progress tracking) and Experiential Memory (skill retrieval). Dedicated Meta-Agent evaluates execution evidence and applies validation-gated updates to skill bank — when agent screws up, it writes down what went wrong and updates tactical playbook rather than repeating same mistake 20 turns later. Improved performance across 37 model-benchmark pairs: +17.8 points to GPT-5.6 Sol on tau-bench, Claude Opus 5 task success to 87.9%, Qwen3.6-27B +16.6, Qwen3.6-35B +13.5 on SkillFlow. Long evaluation tasks: +32.2 points, reduced common failures by up to 80%. Drawbacks: increased latency and higher API costs (dedicated Meta-Agent loop = extra LLM calls per step). LongRCA Bench: failure attribution benchmark for analyzing post-mortem logs of long autonomous agent executions — pinpoints exact turn where agent error occurred during multi-hour runs. Traditional agents struggle on long-horizon tasks because stuffing unformatted execution logs into prompt causes context bloat; after dozens of turns, agents lose track of original goal and start making errors. Expanding context window alone fails to solve fundamental memory loss issue. (3) **Prime Agent: 95.5% on ARC-AGI-3** (AI Weekly, gentic.news) — NEW, MAJOR. Prime Intellect's open-source harness. Prime Agent lifts ARC-AGI-3 RHAE Best@1 from 30% to 95.5% (arXiv Aug 24, 2026). Two abstractions: persistent IPython REPL (Recursive Language Model abstraction for programmatic context processing) + Continual Harness (preserves histories, memories, skills, prompts, subagent specifications across trajectories). "Prevents harness failures from becoming model failures." Matches or exceeds native and popular harnesses on long-context coding, GPU-kernel generation, emulator construction, autonomous nanoGPT speedruns. Factorio: continuous technology progression, parallelized work via dedicated subagents. Opus 5 behind headline number (three runs: 95.0, 95.2, 95.5; Best@3 99.97% covering 183/183 levels). Code on GitHub. Critical notes: self-inventing harness claim is risky — could theoretically weaken benchmark to inflate score. No ablation data (persistent vs reset REPL comparison). Treat as provocative demo rather than settled result. (4) **Agentic Procedural Memory analysis** (DeepContextAI Substack) — NEW. Exhaustive analysis of arXiv:2608.14036. Key finding: agent skills emerge through procedural anchoring (65.7%), not knowledge injection (4.5%). Shift from zero-shot prompt adherence to inference-time, procedurally anchored execution. Failure taxonomy: retrieval collapse, misalignment between steps, fragile memory backups. MAS-vs-SAS economics (multi-agent vs single-agent). Expanded Level 6 maturity map rating agent capabilities and stability. (5) **Lody open-sourced** (Lody blog) — NEW. Shared workspace for teams and coding agents. Brings conversations, runtime state, and code changes scattered across team members, agents, and machines into one space. Team members can open one another's conversations and continue discussions. Start tasks on online machines from browser/phone, add instructions while running. Local-first sync engine built on Loro Stack (CRDT-based — replicas change independently, merge after reconnecting). Open data formats: data should outlast applications. CLI and desktop client open source at github.com/lodyai/lody. Targeting software teams of 20 or fewer. End-to-end encrypted workspaces design completed (not yet implemented). Future: task management, documentation, code review, plugins. (6) **IBM Granite 4.2** (AI Insiders) — NEW. IBM released Granite 4.2: 3B, 8B, 30B dense decoder-only reasoning models, Apache 2.0 licensed. ~15T tokens pre-training per model. Thinking/non-thinking switch (trade latency for reasoning depth per query). Post-training: ~32% agentic data (software engineering, tool calling, terminal use, math, search). Multi-stage RL via GRPO (Group Relative Policy Optimization, same family DeepSeek popularized). 8B and 30B models get additional agentic block: SWE agent (real repo in sealed container, judged by hidden test suite), Terminal agent (live shell via Harbor/Terminus-2, judged on task completion), Search agent (multi-hop web research judged by AI judge model). Native OpenAI-compatible tool calling (OpenCode, Pi, OpenHands without adapters). Quantized variants: FP8, NVFP4, MXFP4, GGUF for edge deployment. CoreWeave-hosted GB200 NVL72-class hardware.

## New Tools & Discoveries

### Cursor Origin
- **What it does**: Git-based code hosting platform embedded inside Cursor's AI editor. Repositories (native or GitHub-mirrored), pull requests, code browsing, two-way GitHub sync. "Git forge for the agentic era."
- **Why notable**: Agent-native alternative to GitHub. Code hosting designed for AI agent collaboration. Rolled out Aug 17 (3 days after SpaceX acquisition). Opt-out by default — no data retention/training policies published. Anthropic cut xAI from Claude access. Community concerns about code custody under SpaceX/xAI ownership.

### Prime Agent (ARC-AGI-3 95.5%)
- **What it does**: Open-source self-improving RLM harness. Persistent IPython REPL + Continual Harness preserving histories, memories, skills, prompts, subagent specs across trajectories. Lifts ARC-AGI-3 from 30% to 95.5%.
- **Why notable**: Persistent REPL mirrors long-lived human work sessions (continuous notebook vs fresh shell per task). Matches/exceeds native harnesses on long-context coding, GPU-kernel generation, emulator construction, nanoGPT speedruns. Opus 5 behind headline (Best@3 99.97%, 183/183 levels). Code on GitHub. Caveat: self-inventing harness claim is risky without ablation data.

### Recuris
- **What it does**: Recursive Experiential-Working Memory architecture for long-horizon agent harnesses. Working Memory (progress tracking) + Experiential Memory (skill retrieval). Meta-Agent evaluates execution evidence, validation-gated skill bank updates.
- **Why notable**: Improves performance across 37 model-benchmark pairs (+17.8 tau-bench GPT-5.6 Sol, 87.9% Claude Opus 5, +32.2 long tasks, -80% common failures). Drawback: increased latency and API costs from Meta-Agent loop. LongRCA Bench for failure attribution in post-mortem logs.

### Lody (Open Source)
- **What it does**: Collaborative workspace for teams and coding agents. Conversations, runtime state, code changes in one space. CRDT-based local-first sync (Loro Stack). Open data formats.
- **Why notable**: Shared understanding layer for software teams + agents. Team members can open/continue one another's conversations. Start tasks from browser/phone, add instructions while running. CLI + desktop client open source (github.com/lodyai/lody). Targeting teams of 20 or fewer. E2E encryption design completed.

### IBM Granite 4.2
- **What it does**: 3B/8B/30B dense decoder-only reasoning models, Apache 2.0. ~15T tokens pre-training. Thinking/non-thinking switch. 32% agentic fine-tuning data. GRPO multi-stage RL with SWE/Terminal/Search agent stages.
- **Why notable**: Small models betting on agentic skill (procedural anchoring, not just benchmark scores). SWE agent: real repo, sealed container, hidden test suite. Terminal agent: live shell, task completion. Search agent: AI judge model. Native OpenAI-compatible tool calling. Quantized variants for edge.
