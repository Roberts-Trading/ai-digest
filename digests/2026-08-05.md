### Letta/Memory — TencentDB Agent Memory #1 GitHub Trending (Four-Tier Pyramid), Zero-Mem (No LLM Calls for Memory), Agent Memory Leaderboard, Graphiti Outperforms MemGPT
- **Summary**: (1) **TencentDB Agent Memory hits #1 GitHub Trending** (ByteIota) — 14,600 stars, nearly 2,000 in one day. Four-tier memory pyramid: L0 (raw conversation), L1 (extracted atomic facts), L2 (recurring scenario patterns), L3 (synthesized team persona). Inverted retrieval: query persona first, raw transcript only if needed. Token savings 33-61%. SWE-bench: 64.2% with memory vs 58.4% without. Token usage dropped from 3.47B to 2.38B (~33% reduction). WideSearch: 51.5% better task success, 61.4% fewer tokens. Short-term context compression: offloads verbose logs to reference files, encodes state transitions as Mermaid diagrams. Four asset types: Skills (procedures), LLM-Wiki (documentation), Code-Graph (code relationships), memory. MIT licensed, local SQLite + sqlite-vec, zero cloud dependencies. Works with Claude Code, Hermes, OpenClaw. Limitation: stores memories but doesn't resolve conflicts or detect staleness. (2) **Zero-Mem** (LavX) — arXiv paper (2607.29377, submitted July 31). Removes LLM calls from memory organization and retrieval. Entity-context graph + temporal hierarchy. Deterministic structures handle memory access — LLM only for final question-answering. 57.6% reduction in memory-operation time vs fastest baseline. Key insight: "Developers often treat memory as a second language-model workflow. Zero-Mem replaces that chain with an index over the trace itself." Code and implementation details to follow peer review. (3) **Agent Memory Leaderboard (AML)** (BestHub) — Launched July 29, 2026 by 20+ universities and research institutes. Unified benchmark for text AND code memory. Two interfaces: `Add` (write memories) and `Search` (return evidence). Fixed Answer model, unified Eval pipeline, multi-agent judging system. Text memory: 7 dimensions (factual recall, multi-hop composition, temporal sequencing, memory governance, personalization, rule/workflow execution, epistemology, security/privacy). Code memory: Debug Memory (past fixes) and Development Memory (architectural patterns). New code-memory dataset from real GitHub repos: 12 repositories, 150 base tasks, 1,290 annotated historical PR tasks. Three relevance levels, strict temporal ordering. (4) **Graphiti by Zep AI** (Zero G Talent) — Open-sourced January 2025. Temporal context graph engine. 29.6K GitHub stars, 35+ contributors. PyPI package graphiti-core v0.29.3. LoCoMo: 94.7% accuracy, 155ms latency, 5,760-token context. LongMemEval: 90.2%, 162ms, 4,408 tokens. Outperforms MemGPT on Deep Memory Retrieval benchmark. Roadmap: custom graph schemas, enhanced retrieval, hardened MCP server. "The enterprise memory race just got a new baseline." (5) **History of agent memory** (Taskade) — MemGPT → Letta (Sept 2024, $10M seed). OpenAI "Dreaming" (June 4, 2026): synthesizes memory in background, revises time-sensitive facts. Factual recall: 41.5% (2024-era) → 82.8% (2026 system). Anthropic memory tool + context editing (Sept 2025): 39% improvement, 84% token reduction.
