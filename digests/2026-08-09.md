### Letta/Memory — "Your Agent Stack Is Solving The Wrong Problem" (Contract Stack), ChatGPT Long-Term Memory, Harness History
- **Summary**: (1) **"Your AI Agent Stack Is Solving The Wrong Problem"** (DEV Community) — The visible agent stack (model, prompt, memory, tools, MCP, subagents, framework, evals) is easy to list. The contract stack is load-bearing. "An agent is a control loop, not a [memory]." Memory is a four-part contract: what gets written, how it's organized, how it's retrieved, how it's governed. Poor memory → sludge (too much), distortion (bad summarization), vibes with citations (similarity-only retrieval), context poisoning (never forgets), invisible authority (can't show why used). "Which state should survive because it will improve future decisions, and which state should expire because it will poison them?" A 500-word well-maintained project note can outperform a giant chat history — the smaller note has a job, the transcript merely has volume. (2) **ChatGPT getting long-term memory** (HeightsTrack) — ChatGPT 1B+ weekly active users. Long-term memory capabilities confirmed. (3) **Agent harness history** (Taskade) — Memory + Intelligence + Execution triple. Key milestones: SWE-agent (May 2024, 12.5% pass@1), Codex CLI (April 2025, open-source), Claude Agent SDK (Sept 2025, context engineering), Agent Skills (Oct 2025, portable capabilities), Agentic AI Foundation (Dec 2025, AGENTS.md adopted by 60K+ open-source projects). 2026: "Harness engineering as a named practice — teams now tune harnesses the way they used to tune prompts." (4) **awesome-free-models** (12britz, GitHub) — Letta listed as framework for long-term agent memory with virtual memory management that pages data in/out of context like an OS. Persistent agents. (5) **KDD 2026 papers** — CoRank (LLM-based compact reranking for scientific retrieval, nDCG@10 50.6→55.5). LitBench (graph-centric LLM benchmarking for literature tasks, small domain-specific LLMs competitive with GPT-4o and DeepSeek-R1). SemStruct (frozen PLMs + GNN for schema matching, state-of-the-art on Valentine/SOTAB-SM).

## New Tools & Discoveries

### Cursor Rules (.cursor/rules/*.mdc)
- **What it does**: Markdown files with YAML frontmatter (description, globs, alwaysApply) stored in .cursor/rules/ at project root. Instructions injected into agent context when file matches globs or alwaysApply is true.
- **Why notable**: Scoped and conditional — only load when matching files are touched. Differ from AGENTS.md (repo-wide) and CLAUDE.md (full context). Right tool for file-type-specific discipline. The third rules system alongside AGENTS.md and CLAUDE.md.

### Agent Plugins (Vercel, open standard)
- **What it does**: Portable package format for bundling Skills and MCP servers. Open, vendor-neutral standard. Compatible clients discover and load consistently.
- **Why notable**: Steering committee includes major agent ecosystem players. Portable across ChatGPT, Codex, Cursor, Copilot, Kiro, VS Code. The standardization layer for agent extensions.

### CoRank (KDD 2026)
- **What it does**: Training-free, model-agnostic reranking framework for scientific retrieval. Three-stage: offline feature extraction, coarse-grained reranking with compact representations, fine-grained on full texts. nDCG@10 50.6→55.5.
- **Why notable**: Addresses suboptimal first-stage retrieval and context-window limitations. Compact representations allow more documents in context window. Open-sourced with AI agent tool.
