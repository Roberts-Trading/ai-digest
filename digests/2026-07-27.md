## Product Updates

### Anthropic — Opus 5 Continued Coverage: Longer Responses, Cyber Classifier Details, Export Control History
- **Summary**: Additional Opus 5 details emerge. ghacks/The Register: Opus 5 responses run longer than prior Opus models — Anthropic advises customers to "prompt for it explicitly" to control response length, since longer responses increase output token costs. Cyber classifiers are proportionally less restrictive than Fable 5: they "allow Opus 5 to find vulnerabilities in source code, but block 'binary-based' vulnerability scanning (a method more likely to be associated with malicious actors), penetration testing, and exploit generation." On OSS-Fuzz benchmark: Opus 5 scores 80% (vs Mythos 5's higher score). On weaponization: Opus 5 succeeds at 1 of 14 attempts vs Mythos 5's 13 of 14 — deliberately weaker at turning flaws into attacks. No data retention requirement for general access — significant for businesses. Fable 5 and Mythos 5 were briefly pulled from public access in June after US Commerce Department imposed export controls (lifted end of June). Dianne Penn (Anthropic product leader): "We're building and continue to consistently deliver frontier intelligence and bring that as accessibly as possible with every model generation." Verdict: Opus 5 shows 10.2 percentage point improvement in molecular structure inference and 7.7 point increase in protein-related tasks over Opus 4.8. Available via `claude-opus-5` endpoint. Fast mode: ~2.5× standard speed at 2× base rate.

### Letta/Memory — NVIDIA NOOA Framework, Uteke Local Memory Engine, Hermes Agent 214k Stars
- **Summary**: (1) **NVIDIA NOOA (NVIDIA Labs Object-Oriented Agents) framework** — Open-source, Python-based. Optimizes AI agent harnesses (the system layer surrounding models) rather than changing base models. Claims double-digit percentage improvements on benchmarks, 50% token usage reduction. SWE-Bench Verified: 82.2% accuracy with GPT-5.5 (vs 79.2% prior SOTA), using 1.1M tokens vs 2.2M. CyberGym L1: 86.8% task completion (top among open-source agents). ARC-AGI-3: 85.1% RHAE with GPT-5.6-sol, under $20/task. Pass-by-reference mechanism and efficient context management. Knowledge accumulation across sessions without retraining, stored in human-readable SQLite file. Research preview on NVIDIA GitHub. Pair with NVIDIA OpenShell runtime for secure deployment. (2) **Uteke: local-first semantic memory engine in Rust** — Single binary, no Docker (optional), no API keys, no cloud. ~45ms full pipeline, ~5ms vector recall at 10K entries. Local embedding model (188MB, downloads once). Vector search + SQLite FTS5 full-text search, merged with Reciprocal Rank Fusion. Data stays at `~/.codecora/uteke/`. 148 stars, 16 forks. Apache 2.0. Install: curl, homebrew, or cargo. (3) **"Why AI Memory Systems May Become More Important Than the Models Themselves"** (AI Journal) — Enterprise AI limiting factor is increasingly memory, not intelligence. Retrieval solves part of the problem but doesn't create memory coherence. Need: awareness of previous actions, workflow dependencies, decision history, organizational constraints, user preferences, evolving execution state. Long-context models help temporarily but don't solve structural memory management. "Intelligence without continuity quickly becomes difficult to trust." (4) **Hermes Agent (Nous Research): 214k+ GitHub stars in 6 months** — Fastest-growing open-source agent framework of 2026. Persistent cross-session memory + self-improving skill loop. Architecture: persistent memory, auto-generated skills, session history, scheduling, delegation, web tools, isolated sandboxing (local, Docker, SSH, Singularity, Modal). Desktop preview (June 2). `hermes claw migrate` command imports OpenClaw and legacy setups (memory, skills, persona, settings, credentials). Nous Portal subscription for monetization. MIT-licensed runtime. (5) **OPPO Xiaobu Next** — On-device multi-agent AI assistant with full-domain memory. Always-on sensing. Proactive behavior (acts before you prompt). 13 eligible devices (9 OPPO Find, 4 OnePlus). 100+ system actions. Third-party agents (Luckin Coffee, Evernote, Fliggy, Meituan). Privacy: explicit authorization for habit tracking, on-device by default, cloud via "secure private compute pathway" only when necessary, critical actions (email, payments) require confirmation.
- **Source**: https://blockchain.news/news/nvidia-nooa-ai-agent-performance ; https://dev.to/ajianaz/i-built-a-memory-engine-for-ai-agents-no-cloud-required-47mo ; https://aijourn.com/why-ai-memory-systems-may-become-more-important-than-the-models-themselves/ ; https://startupfortune.com/hermes-agent-crosses-214000-github-stars-as-developers-abandon-commercial-ai-agent-frameworks/ ; https://www.androidpure.com/oppo-xiaobu-next-eligible-devices/
- **Significance**: NVIDIA entering the agent framework space with NOOA is a major signal — the GPU company is now optimizing the harness layer, not just the compute layer. The 50% token reduction with better accuracy is the harness-engineering thesis proven at scale. Uteke is the local-first memory pattern: Rust binary, 45ms pipeline, no cloud dependency, $0 cost — the same economics as the dual-tier architecture from yesterday but in a single binary.
