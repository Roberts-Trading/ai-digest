### Letta/Memory — Agent Memory Layer Comparison (Letta Repo Status Change: Development Shifted to letta-code), Anansi Open-Source Personal Web Memory, Runtime Controls Framework (ETH Zurich 20% Cost Finding), Context Engineering Inside the Harness
- **Summary**: (1) **"Choosing an Agent Memory Layer: 7 Critical Decision Points"** (BestHub, Sept 13) — NEW, notable. Compares Mem0, Graphiti, Letta, Cognee, Supermemory, Mnemovela across write timing, conflict resolution, forgetting strategies, context assembly. Letta: OS-style paging + self-editing, three tiers (Core = resident in context, Recall = searchable history, Archival = vector-indexed cold storage); when context nears overflow the agent decides what to evict, summarize, or archive — "the OS metaphor is literally implemented." Critical 2026 change flagged: the Apache-2.0 letta-ai/letta repo (~24.4k stars) is now a landing page; V1 server moved to archive branch; active development shifted to letta-ai/letta-code. Current SDK uses MemFS (git-backed memory filesystem); commands /init, /remember, /doctor. Unique capability: Dreaming — background sub-agent reviews recent conversations, consolidates lessons, updates memory without interrupting work, with optional second-pass verification. Lock-in asymmetry: "Mem0 locks at API level; Letta locks at architecture level — adopting it means adopting a full agent lifecycle model." (2) **Anansi** (DEV Community, Sept 13) — NEW. Open-source personal web memory for coding agents: browser extension captures what you save (X, Reddit, GitHub, deliberate web capture), library keeps it searchable, read-focused MCP server lets agents search and pull saved references into context. BM25 keyword search on MCP; semantic search a separate optional path. Bearer-authenticated ingest, SQLite locally, Cloudflare deployment path. (3) **Runtime controls framework** (encorp.ai, Sept 13) — NEW. Reliability is moving from the model layer into integration architecture; four controls in order: context budgeting (hard thresholds for tool outputs), compaction (structured summaries preserving intent/constraints/artifacts/next steps), todo-state (for branching/long workflows), persistent memory (last, only for repeating workflows). Key cost finding from ETH Zurich study: always-on repository context files (AGENTS.md etc.) raised inference costs 20-23% (LLM-generated) and up to 19% (developer-committed) without consistent success gains. (4) **Context engineering inside the harness** (NCIJ Network, Sept 13) — NEW. Mechanism survey across LangChain Deep Agents, Claude Code, Manus, OpenAI Codex, Amazon Bedrock AgentCore. OpenAI Responses API now offers server-side compaction (context_management with compact_threshold, plus /responses/compact returning an encrypted compaction item to pass unchanged into the next call — Codex relies on this). Claude Developer Platform exposes compact_20260112 with custom instructions (which replace the default prompt entirely — "a compaction prompt is a real engineering artifact, not a setting") and pause_after_compaction. Claude Code re-injects CLAUDE.md and auto memory from disk after every compaction. Guidance: keep CLAUDE.md under 200 lines; move reference material into skills or path-scoped rules that load only when needed. (5) **Memanto agentic memory course** (Web Pulse, Sept 13) — NEW. Four memory types (working, episodic, semantic, procedural) on two clocks: within a run memory is a survival problem, across runs a compounding problem. 13 semantic types instead of raw text blobs; failure records ("error" type) highlighted as the type nobody stores but everybody needs. (6) **Claude Sonnet 4.5 memory tools retrospective** (PulseAugur/dev.to, Sept 13) — continuation. Beta memory tool stores/retrieves outside the context window; per-agent only — no cross-session or cross-application end-user memory; developers build the underlying system.

## New Tools & Discoveries

### Prove2Me
- **What it does**: Open-source tool that helps AI agents pick the most useful next step during long multi-stage research workflows while cutting inference costs. Enabled Claude's Fermat formalization.
- **Why notable**: The unlock behind the 11-day, 13M-line formalization. Anthropic is expanding free access and research credits for mathematicians using it on formalization projects.

### Anansi
- **What it does**: Open-source personal web memory for coding agents — browser extension captures saves from X/Reddit/GitHub/web, searchable library, read-focused MCP server for agent retrieval.
- **Why notable**: Personal-curation memory (what the human deliberately saved) as an alternative to auto-captured everything. Bearer-authenticated, local SQLite, explicit capture only.

### Memanto
- **What it does**: Memory store tagging every entry with one of 13 semantic types (fact, preference, event, error, instruction...) instead of raw text blobs; typed remember/recall commands, session handoffs, structured failure records.
- **Why notable**: The "error" type — structured records of what went wrong and the fix that worked — is the memory category the course author argues nobody stores but everybody needs.
