### Anthropic — Claude Cowork Expands to All Paid Plans, Claude Can Now Send Gmail Emails, Widespread Outage (7 Incidents in 6 Days), Claude Designs Protein Binders for Drug Discovery (14/15 Targets), Sonnet 5 Price Hike Reversed, Claude Code Token Optimization
- **Summary**: (1) **Claude Cowork expands to all paid plans** (The Verge, 9to5Mac, RuntimeWire) — Anthropic announced Claude Cowork is now available on mobile and web for all paid accounts (Pro $20/mo, Max $100/$200/mo, Team). Previously limited to desktop and most expensive plans. Sessions and files attach to Claude accounts, enabling task continuity across desktop, web, and mobile. Enterprise access controlled by administrators. Still labeled beta. Anthropic positions Cowork as the primary interface for task delegation, with chat reserved for questions. (2) **Claude can now send Gmail emails** (9to5Google, iTechPost, NewsBytes, Abijita) — Claude's Google Workspace connector now supports sending, replying to, and forwarding emails from Gmail. Previously Claude could only read, search, summarize, and draft emails. Default setting requires user approval before sending, but users can configure it to send without approval. On Team and Enterprise plans, owners decide whether members can skip approvals. Also added Google Drive file management. Available only on paid Claude plans. Moves Claude from drafting assistant to one that can complete full email tasks autonomously. (3) **Widespread Claude outage** (Startup Fortune) — Claude went down across every major model on August 18. Downdetector logged 4,000+ user reports within an hour. Status page incident opened at 16:20 UTC for degraded performance affecting Claude Mythos 5, Fable 5, Opus 5, Sonnet 5, Haiku 4.5, and others. Hit claude.ai, Claude API, Claude Code, and Claude Cowork. By 17:12 UTC still investigating Opus 5 errors. This is the latest in a run of at least 7 incidents over 6 days: Aug 12 (degraded multiple models), Aug 13 (elevated errors Mythos 5/Fable 5/Sonnet 5), Aug 14 (Claude Code web + API/Code/Cowork disruptions), Aug 15 (Fable 5 issue resolved), Aug 16 (auth trouble + service disruption), Aug 17 (degraded Opus 5/Sonnet 5), Aug 18 (broad outage). "Not whether one incident clears, but whether the pattern does." (4) **Claude designs protein binders for drug discovery** (Times Now, CNBC TV18, AI Weekly) — Anthropic tested Claude (Mythos Preview and Opus 4.8) on protein design for early drug research. Partnered with Adaptyv Bio and Twist Bioscience for independent lab testing. 30 designs per target × 15 targets = 1,320 designs. Lab testing found 354 binders against 14 of 15 targets. Hit rates: Mythos Preview 35.1% (per-target sessions), 26.7% (all targets, 48-hour session); Opus 4.8 22.6%. Typical industry hit rate: 10-15%. For at least 4 targets, Claude's binders matched or exceeded best previously reported binding strength. Failed on MBP (maltose-binding protein, 0/90 confirmed) and BBF-14 (synthetic β-barrel, limited success). Claude also processed NMR data in 23 min and LC-MS in 19 min, purity within 0.1% of lab's reading (96.4% vs 96.33%). Dual-use biology capabilities remain restricted from general access; Anthropic preparing trusted access program for scientists. "Foundational work" toward end-to-end drug development. (5) **Sonnet 5 price hike reversed** (IBTimes SG) — Anthropic canceled Claude Sonnet 5's planned API price increase on August 10, making introductory rates permanent: $2/M input, $10/M output (was supposed to jump to $3/$15 on September 1). No detailed public explanation. Possible factors: reported interest in inference startup Decart acquisition, competitive pressure. Higher token consumption can still raise production costs despite unchanged headline price. (6) **Claude Code token optimization** (The New Stack) — Anthropic's /claude-api skill was silently consuming 200K tokens per request. Claude Code v2.1.234 cuts that to ~25K tokens (85.7% reduction) by loading reference documentation on demand. Previously embedded all reference files and language docs directly into skill body (~120K tokens of reference material, one migration doc alone was 36K tokens). On-demand loading may require extra file read after identifying relevant language/API, but only pulls cost for material tied to the task. "The blank-check era of AI coding is ending."

### Letta/Memory — Notion Lore (Open-Source Shared Memory), Warp Agent Memory (Governance Problem), Files vs Structured Stores vs Trained Memory Head-to-Head (Letta Referenced), Agent-Scoped Memory, Memorify 12ms Context Gateway, Starling UCA Open Standard, Sharing Claude Code Memory with Teams
- **Summary**: (1) **Notion Lore: open-source shared memory** (Notion blog) — Lore is shared, persistent memory for AI agents backed by Notion. MIT-licensed at github.com/makenotion/lore. A Lore vault is a Notion page with 5 databases. Agents access via MCP (lore-* tools). Humans access via Notion directly or Lore CLI. Hooks make it hands-off: sessions start with context, store/fetch as needed, save in background. Facts expire by default — must be continually reinforced. Addendums use relations (supersedes, scoped, conflicts_with). CLI tooling for orphaned facts, duplicates, memory debt. Eval: SkillRet dataset (4,997 queries, 6,660 skills). Seeded memory agent recovered ~46% of failures on hardest tasks. Built as 20% project. (2) **Warp Agent Memory: governance problem** (AI Insiders) — Warp opened research preview of Agent Memory. Agents keep what they learn across sessions, even on different machines. Three store types: Personal (single user), Agent (default, per-agent), Team (shared institutional knowledge). Access not all-or-nothing: read-only or full read-write per agent attachment, with instructions on when to consult. Memory created automatically at conversation end (extracts facts, decisions, results). Background writes/retrieval, no token cost or task slowdown. Missing for enterprise: no programmatic API, no self-hosting, no third-party local harness support (Claude Code, Codex). Design partners only, waitlist. "Convenience across your own machines and convenience across other people's work are different problems." (3) **Files vs structured stores vs trained memory** (AI Insiders) — Independent researcher Ping Lin tested three memory architectures head-to-head. Files (curated index + topic files, used by Claude Code auto-memory, Cline Memory Bank, Cursor, Windsurf) vs Structured store (atomic embedded facts, sold by mem0, **Letta**, Zep) vs Trained memory (RL-trained retrieval, MemHarness). Results on LongMemEval (500-question suite): Structured store 73.6%, Files 44.9% — 28.7-point gap (95% CI: 22.1-35.4). Structured store also cheaper: ~27K tokens per correct answer vs ~665K for files. Trained memory scored 87.4 on hardest bar (63-66 for all untrained arms). Guidance: coding agents with small legible history → files + abstention check. Cross-session recall at scale → structured store. Training into weights only if base model has headroom. "Agents are accumulating state faster than anyone has built discipline for containing it when that state turns out wrong." (4) **Agent-scoped memory in Deep Agents** (prodSens.live) — Agent-scoped memory: all conversations using same agent access same long-term memory. Key difference: use fixed agent ID as namespace instead of user ID. Thread ID still matters for conversation state but doesn't create separate memory namespace. Use when memory describes the agent, project, or shared environment rather than a specific user. LangGraph/LangSmith store for persistence. (5) **Memorify 12ms context gateway** (DEV Community) — Unified gateway ("motherboard") for AI agents. Centralizes vector storage, memory, OAuth connectors behind single endpoint. ~12ms real-time context bus. Stack: Deno Deploy (edge V8 isolates, zero cold-start), Neon Postgres (serverless relational + pgvector), ElectricSQL (partial DB replicas over HTTP, active-active sync). Zero-reboot dynamic updates: MCP server changes stream live to connected agents. Leak Vault for AES-256-GCM encryption of API keys/tokens. Durable memory, searchable documents, skills, agent access levels. (6) **Starling UCA open standard** (Datacenter News) — Starling Memory Works published Universal Cognitive Architecture (UCA) as free open standard (Creative Commons). Introduces "Domain Language Model" — stateless LLMs reasoning over external repository. Knowledge stored at fixed semantic addresses, retrieved by coordinate not search. Uses MCP (Anthropic's standard) to connect models. Dual repository: Org Library (versioned plain-text decisions/standards/processes) and Resources (PDFs, decks, formatted files). Reduces dependence on proprietary storage. Starling MX beta platform: $99/mo first seat. Constitutional Memory setup in a few hours. (7) **Sharing Claude Code memory with teams** (DEV Community) — claude-mem stores memory locally in SQLite. Team sharing not built in (issues #2420, #1415, #1981 request MySQL/Postgres/Turso backends). Paid cloud sync is per-user, multi-device, not multi-person. Third-party claude-mem-sync adds team sharing via GitHub Action + Claude Code plugin. Alternative: kg (knowledge graph) with S3-compatible bucket sync. Each writer gets own shard, write-once objects, no textual conflicts. 1M decisions across 30 writers, ~100ms decision lookup. Local-first, no server. (8) **AI Agent Stack 2026** (DEV Community) — Three memory layers: ephemeral working (context window + Redis), durable task (Postgres, not vector DB — "most 'we need an agent memory system' conversations resolve to a tool_calls JSONB column and a step_count integer"), semantic (pgvector or Qdrant/Weaviate). Event-driven/queue-based architecture (Redis Streams, RabbitMQ, SQS). "The single biggest reliability upgrade you can make to an agent system, and almost nobody does it on day one." (9) **Sizing agent memory** (Groundy) — Capacity planning, not prompt engineering. Measure per-run input tokens first, verification at stage boundaries second, indexed retrieval or compressed state only after cheaper levers stop paying. EgoCITE (arXiv:2608.12627): EgoScheme, EgoIndex, EgoRetrv — 36× lower cost than long-context LLM agents. IBM ALTK-Evolve-HMM unverified. ## New Tools & Discoveries

### Notion Lore (Open-Source Shared Agent Memory)
- **What it does**: Shared, persistent memory for AI agents backed by Notion. MIT-licensed. Lore vault = Notion page with 5 databases. Agents access via MCP (lore-* tools). Expiratory facts (must be reinforced). Relations (supersedes, scoped, conflicts_with). CLI for memory debt management. Hooks for hands-off operation.
- **Why notable**: Open-source, Notion-native, MCP-based. Eval: 46% failure recovery on hardest tasks. Built as 20% project. Practical shared memory without infrastructure.

### Warp Agent Memory (Shared Memory Across Sessions and Teams)
- **What it does**: Persistent agent memory across sessions and machines. Three store types: Personal, Agent (default), Team (shared). Read-only or read-write per attachment. Automatic fact extraction at conversation end. Background writes/retrieval.
- **Why notable**: Team stores enable institutional knowledge sharing. Governance as core problem (access control, instructions per attachment). Missing: API, self-hosting, local harness support.

### Memorify (Unified Context Gateway, 12ms Sync)
- **What it does**: Centralizes vector storage, memory, OAuth connectors behind single endpoint. ~12ms real-time context bus. Deno Deploy + Neon Postgres + ElectricSQL. Zero-reboot MCP server updates. AES-256-GCM key encryption.
- **Why notable**: Sub-15ms cross-agent synchronization. Edge routing with zero cold-start. Active-active replication via ElectricSQL shapes.

### Starling UCA (Open Standard for Domain Language Models)
- **What it does**: Universal Cognitive Architecture — stateless LLMs reasoning over external repository. Knowledge at fixed semantic addresses, retrieved by coordinate not search. MCP integration. Dual repository (Org Library + Resources). Creative Commons licensed.
- **Why notable**: Reduces vendor lock-in. Plain-text knowledge base. $99/mo Starling MX platform. Constitutional Memory setup in hours. UK £1.1B AI sovereignty context.

### Grok Bot (Always-On AI Agents)
- **What it does**: Always-on AI agents on cloud computers. Multiple bots in parallel, one manages a team. Bots message each other, pass work, assign ownership, escalate for judgment calls. Group chat. Browser-based interaction (not APIs). $120-$300/month. Beta.
- **Why notable**: Shifts from "best answer" to "finished work." Multi-agent coordination with human escalation only for judgment calls. X API preferential access coming. No published benchmarks.
