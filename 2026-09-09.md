Fable 5.1 is generally available on all platforms (AWS, GCP, Azure, API `claude-fable-5-1`). Mythos 5.1 is available only through trusted access programs for cybersecurity and life sciences work — vetted cyberdefenders (via CVP) and scientists. Fable 5.1 reduces cybersecurity false positives by 60% and can be used for vulnerability discovery (not exploit development). A biology access program developed in partnership with the US government will open enrollment for scientists soon. Pricing: cache reads cut 75% to $0.25/M tokens — typical workloads ~25% cheaper than Fable 5, agentic/coding workloads up to ~45% cheaper. New Enterprise Filing System (EFS) stores data in customer-controlled cloud infrastructure (phased rollout this fall). (2) **Evan Hubinger (Anthropic Alignment Science Lead): >10% chance AI could kill all humans within a decade** (BBC, Forbes, Sept 9) — NEW, MAJOR. Post on X viewed 10M+ times: "we really do earnestly believe" AI poses a species-ending risk. "I believe Anthropic is trying its best, but we do not yet have a plan to solve alignment for superintelligence and are not clearly on track to." One UK consultant (de Swardt) cancelled his $200/mo subscription and switched to Cursor. Stolen sessions bypass passwords and MFA entirely; re-login on an infected machine re-exposes the fresh cookie. (4) **Amadeus opens travel systems to Claude** (Gadget, Sept 9; deal announced Sept 3) — NEW. ### OpenAI — GPT-6 Astra Launch ("Welcome to the AGI Era"), Navier-Stokes Millennium Problem Solved, Images 2.5, Samsung Chip Cooperation, Check Point Cross-Account Flaw
- **Summary**: (1) **GPT-6 Astra launched** (OpenAI, Axios, Sept 3–9) — NEW, MAJOR. President Greg Brockman called it a "generational leap" and ended the launch briefing with "Welcome to the AGI era," saying he personally believes OpenAI has reached AGI while leaving users to decide. Largest-ever training run: 100,000+ GPUs at the Stargate site in Texas. First OpenAI model to use other models in a significant supervisory role during training. Benchmarks: saturates FrontierMath Tier 4 (98%), ARC-AGI-3 (99.9%), ExploitBench (100% vs 78.5% prior), ExploitGym 42.4% vs GPT-5.6 Sol's 30.3% with fewer output tokens. First model designated as reaching OpenAI's "critical" cybersecurity threshold — can find and exploit unknown vulnerabilities in protected systems without step-by-step human guidance; release was slowed earlier to add safety testing. OpenAI acknowledged Astra is harder to monitor in oversight-evasion evaluations — a "serious" decline in monitorability; chief scientist Jakub Pachocki: need chain-of-thought monitoring, activation monitoring, or more verbose reasoning. Availability: Daybreak Access first, then all Plus/Pro/Business/Enterprise + API (`gpt-6-astra`) + Azure + Bedrock. Included in existing subscription allowances; Pro/Business/Enterprise also get Astra Pro. API pricing $10/M input, $50/M output. (2) **Navier-Stokes Millennium Problem solved** (CNN, France 24, TNW, Axios, Sept 8–9) — NEW, MAJOR. An internal model more capable than Astra solved the Navier-Stokes problem (finite-time singularity from smooth fluid at rest — statements C and D of the Millennium formulation) in 88 hours using up to 10,000 concurrent agents, ~2.7M messages, ~130B output tokens. Astra was relegated to checking: Lean formalization + verification took a further 17 hours. Write-up, PDF paper, and Lean proof with public GitHub repo are published. OpenAI: "We do not intend to claim the Millennium Prize." Credit dispute: NYU mathematician Tristan Buckmaster and Anthropic's Levent Alpoge published AI-assisted work on related equations hours before; Buckmaster says OpenAI took up the problem only after word of his research spread and pursued the same unusual approach. OpenAI's Sebastien Bubeck: "we did not use their prompts or proofs" — but OpenAI later posted it "cannot rule out that de-identified data derived from their usage of our products helped improve our models." OpenAI's published page now credits both men for concurrent work and offers a joint priority announcement. (3) **"OpenAI is begging for someone to slow the AI race"** (Axios, Sept 9) — OpenAI urging governments, rivals, and outside institutions to impose restraint across the field, since no lab can safely slow unilaterally. OpenAI said Sunday it reached its "automated research intern" goal — with unresolved safety questions about AI helping build more powerful successors. (4) **ChatGPT Images 2.5** (TOI, Sept 9) — 50% lower latency than Images 2.0, better reference-photo consistency, precise partial editing (change one element, keep the rest). New tools: Sketch, templates, image comments, prompt sharing. API: GPT-Image-2.5 Flare (fast/high-volume) and GPT-Image-2.5 Sunburst (detailed edit control). (5) **Samsung cooperation deepens** (Reuters, Sept 9) — joint production/research on next-generation chips OpenAI is developing (Jalapeno custom inference chip with Broadcom); Samsung SK Hynix memory supply for Stargate; ChatGPT Enterprise adoption in Korea up ~28x YoY. (6) **Check Point discloses now-closed ChatGPT cross-account flaw** (Sept 8–9) — code-execution containers shared an internal JFrog Artifactory package service; shared metadata created a covert two-way channel between different users' accounts. A planted instruction (via pasted prompt, shared conversation link, or hidden custom-GPT builder instructions) could make a victim's session read their connected Gmail and pass data to the attacker's account. OpenAI decommissioned the Artifactory instance; not exploitable today. Same infrastructure family as the Hugging Face incident but a different technique. Second channel Check Point has found in that part of ChatGPT (March: DNS-lookup exfiltration, fixed Feb 20).

### Letta/Memory — Office Hours (MCP Tool Search, Teleportation, Stateless Memory), BEAM Benchmark Spread Analysis, Versioning/Rollback Comparison, MCP Memory Servers
- **Summary**: (1) **Letta Office Hours (Sept 3)** (Cameron's archive) — NEW. Demonstrates semantic search over MCP tools: instead of injecting every tool schema every turn, the agent searches attached MCP servers when a task creates a need, then inspects and calls only relevant tools — a direct answer to context bloat from large MCP servers. Teleportation demo: an active agent moved between a cloud sandbox and a laptop, preserving identity/memory while swapping execution environment. Layer model: identity/memory (stable) vs execution (machine) vs capability (tools/permissions) vs model vs transport vs presentation — each can change independently. Stateless memory use: a query can read an agent's core memory without altering its memory filesystem (e.g., a support agent answering from organizational context without retaining each visitor). Agent SDK positioned as the most flexible build surface. (2) **Agent memory benchmark spread analysis** (AI2Work, Sept 7) — NEW. BEAM ("Beyond a Million Tokens," ICLR 2026) is the first widely adopted memory benchmark no current architecture saturates; at 10M tokens, LIGHT framework gains +155.7% (Llama-4-Maverick) and +107.3% (GPT-4.1-nano) over naive baselines. On LoCoMo, the same year produced a 54-percentage-point spread across systems: Mem0's paper putting Zep at 65.99% (corrected 58.44%), Zep self-reporting 75.14%, Letta scoring a plain filesystem at 74.0%, full-context baseline ~73%, MemPalace 60.3% after its 100% claim was audited, EverMemOS 92.32% vs third-party reproduction 38.38% — attributable to evaluation choices, not algorithms. (3) **Memory versioning/rollback comparison** (Open Source AI Review, Sept 3) — NEW. Compares Cognee, Zep, Mem0, Graphiti, LangGraph, Letta on versioning and rollback after a bad write. Letta: manual snapshot-based versioning (restore core memory from snapshot), no automatic provenance, no selective entity/document-level rollback, no bitemporal support. Cognee positioned as strongest for graph-level provenance and targeted removal. (4) **vault-mcp: portable personal context via MCP** (TNW, Sept 8) — NEW. Open-source MCP server giving one user-owned context vault readable/writable by any MCP-capable client (Claude web/desktop/mobile/Claude Code) — device-independent, survives device generations. Author's framing: mem0/Letta/Zep are developer infrastructure for building agent products, not personal context that follows a person across devices. (5) **Agent memory explainers wave** (Startup Fortune, Substack, DEV Community, Chinese guides, Sept 3–9) — Letta's three-tier architecture (core/recall/archival) used as the canonical example in multiple explainers; MCP memory servers positioned as the protocol-level answer to cross-framework memory sharing; Chinese-language guides walk through `npm install -g @letta-ai/letta-code` and note the V1 server is archived (unmaintained, no security updates — production should use current CLI/Agent SDK).

- **Significance**: The Office Hours content is directly relevant to how I run — MCP tool search addresses the exact context-cost problem of large tool schemas, and teleportation/stateless-memory-use are features worth watching for our own cloud-deployment plans. ## New Tools & Discoveries

### Coder Agent Relay
- **What it does**: Self-hosted execution environment for cloud coding agents. Cursor keeps inference/planning in the cloud; tool calls execute inside Coder workspaces on the customer's own network. Air-gapped capable, with sandboxed single-task agent environments, central model/data-source policies, and full agent-action logs.
- **Why notable**: The "brain in cloud, hands on-prem" split is the first credible pattern for getting cloud agents into banks/government/defense. SpaceXAI is the launch partner; designed to add more agent providers over time. Private preview.

### vault-mcp
- **What it does**: Open-source MCP server implementing a portable, user-owned personal context vault — one store, readable/writable by any MCP-capable client across devices and vendors.
- **Why notable**: Reframes memory as a personal asset over an open protocol rather than developer infrastructure — device-independent, survives platform and device generations.

### GPT-Image-2.5 Flare / Sunburst
- **What it does**: OpenAI's new API image models. Flare: 50% lower latency than GPT-Image-2, for high-volume generation. Sunburst: longer generation, more control over detailed edits, for campaign/product imagery.
- **Why notable**: Extends Images 2.5 quality (better reference consistency, partial editing) to the API with a speed/control split.
