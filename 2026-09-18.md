### Anthropic: Claude Now Leads 26% of Its Own R&D
- **Summary**: Anthropic disclosed that Claude "leads" 26% of the company's model R&D as of August — up from ~1% in March (measured on an Epoch AI scale) — meaning it completes most of a task end-to-end from a high-level prompt under human supervision. About 90% of R&D happens "in collaboration" with Claude, but no measured subset is fully autonomous. Anthropic also disclosed ~30,000 agents doing research/engineering work, with every action screened: of 1B+ decisions in August, ~1 in 47,000 was blocked (~0.002%), with ~50 high-priority escalations weekly. Safety compute: 6% of research compute in a July sample week, rising to 12% for AI-driven research.
- **Source**: https://www.nbcnews.com/tech/tech-news/anthropic-says-model-claude-helping-build-next-version-rcna598494
- **Significance**: The clearest public window yet into progress toward recursive self-improvement. Anthropic published the metrics explicitly so the public can track how close labs are to a model autonomously building its successor — and invited other frontier labs to publish the same. The disclosure lands mid-safety-debate, days after OpenAI's misalignment framework.

### Hackers Used Claude to Breach OpenAI
- **Summary**: Security firm Hacktron (three-person team) chained two flaws to take over OpenAI employee ChatGPT/Codex accounts: a libheif heap overflow in Discourse (OpenAI's community forum) plus an OpenAI-side SSO flaw where forum sign-in tokens carried excessive permissions granting full API access to associated accounts. They demonstrated impact with a harmless pull request to OpenAI's internal monorepo, then stopped and reported. OpenAI fixed its side in ~14 hours; $6,500 bounty paid. Key detail: Claude Opus 4.8 couldn't build a working exploit — Opus 5 produced one in ~3 hours after release. Claude Mythos (strongest cyber model, restricted to vetted cyber-defense orgs) was not used.
- **Source**: https://techcrunch.com/2026/09/18/researchers-used-anthropics-claude-to-hack-into-openai/
- **Significance**: A concrete demonstration of the Critical-cyber tier in action — one model generation was the difference between failure and a working exploit against a frontier lab's infrastructure. Also notable: SaferAI found Z.ai's open-weight GLM-5.2 only a few months behind GPT-5.5/Opus 4.7 in cyber capability, so this won't stay a frontier-lab-only problem.

### OpenAI Launches Astra for Law + Own Legal Index

On Vals AI's Legal Research Bench validation set, Astra for Law passed 54.0% of correctness checks at highest reasoning effort vs 38.7% for GPT-6 Astra with plain web search. 26 partner plugins (Relativity, Clio, iManage, Thomson Reuters HighQ, CoCounsel preview), Harvey and Legora building on the API. - **Source**: https://thenextweb.com/news/openai-astra-for-law-gpt-6-legal-search-index

### AgentMemora — Coding-Agent Memory Inspector
- **What it does**: Local inspection and context-control layer over existing coding-agent state (Claude Code best supported): discovers session history, distinguishes primary sessions from subagent transcripts, flags memory conflicts and stale-memory candidates, exports "Context Capsules" for portable context. Working toward "Context Surgery" — selecting only the context worth carrying forward.
- **Source**: https://dev.to/hailneed/your-coding-agent-remembers-more-than-memorymd-so-i-built-a-local-inspector-for-it-1c39
- **Why notable**: Memory intelligence (auditing what agents remember) is emerging as its own niche alongside memory storage.

### Orbital — Cross-LLM Context Sharing
- **What it does**: Open-source tool that persists project context as plain files so agents can hand off mid-task — the demo shows Claude Code hitting a usage cap and Codex continuing with full project context. Each worker writes its own memory file; results get filtered and written back.
- **Source**: https://6ic.com/news/orbital-empowers-ai-teams-to-share-context-across-model-sessions
- **Why notable**: File-based context as the interoperability layer between competing agents — the same file-first pattern Letta, Grok Build, and the OpenCode memory plugin all converged on this week.
